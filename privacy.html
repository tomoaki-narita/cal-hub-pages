複数のカレンダー連携、対応する勤務表PDFの取込み、データの保存先について説明します。

This policy explains calendar integrations, work schedule PDF import, and where app data is stored.

最終更新日: 2026年10月14日

Last updated: October 14, 2026

Calendar Hub（Cal Hub）は、Appleカレンダー、Googleカレンダー、Notionデータベースを切り替えて予定を管理するアプリです。対応する勤務表PDFから予定を取り込んで選択中の登録先へ登録する機能もあります。このポリシーでは、アプリが扱う情報と保存先を説明します。

アプリが扱う情報

01 / 端末内

勤務予定とアプリの設定

ユーザーがスキャンするPDF、PDFから読み取った勤務予定、イベント設定、表示設定、登録先の設定を扱います。

02 / iCLOUD

ユーザーが選んだ同期データ

iCloud同期を有効にした場合、同期対象として設定されたデータと保存済みPDFを、ユーザー自身のiCloud領域に保存します。

03 / 外部サービス

カレンダーとデータベースの情報

Appleカレンダー、Googleカレンダー、Notionの情報は、ユーザーが該当サービスへの接続や取得・登録を行う際に扱います。

カレンダー連携

ユーザーが連携するサービスと登録先を選び、予定の取得や登録を操作したときに、アプリはその機能に必要な情報を各サービスへ送信します。予定の編集・削除など、アプリが対応する操作も、ユーザーがアプリで実行した場合に行われます。

Google Calendar API: Googleとの接続では、カレンダー一覧や予定の表示、ユーザーが選択した予定の登録・編集・削除にGoogle Calendar APIを使用します。OAuthのアクセストークンとリフレッシュトークンは、端末のKeychainに保存します。

Googleユーザーデータは、ユーザーが要求したカレンダー機能の提供にのみ使用します。広告目的には使用しません。Google APIから受け取ったデータの利用は、Google API Services User Data Policy（Limited Use要件を含む）に従います。

Notionのアクセストークンなどの認証情報は、アプリ内Aboutに記載のとおり、端末の安全な保存領域で管理します。

保存と共有

スキャンしたPDF、イベント設定、登録先の設定は端末に保存されます。iCloud同期を有効にした場合は、同期対象の設定と保存済みPDFがユーザー専用のiCloud領域に保存されます。Appleカレンダー、Googleカレンダー、Notionの情報が各サービスへ送信されるのは、ユーザーが接続・取得・登録を実行した場合です。

広告と外部サービス

このアプリは、ユーザーが選択したPDFやカレンダーの内容を広告目的で利用しません。各カレンダーサービスの利用や、各サービス上でのデータ保存には、それぞれのサービスのポリシーが適用されます。

お問い合わせ

プライバシーやデータの取り扱いに関するお問い合わせは、サポートページからお送りください。データを含めてお問い合わせを行う場合は、個人情報や秘密情報を除いてください。

Calendar Hub (Cal Hub) lets users switch between Apple Calendar, Google Calendar, and Notion databases to manage events. It also supports importing events from compatible work schedule PDFs into the selected destination. This policy explains the information handled by the app and where it is stored.

Information handled by the app

01 / ON DEVICE

Schedules and app settings

The app handles PDFs selected for scanning, schedule information read from those PDFs, event definitions, display preferences, and calendar destination settings.

02 / ICLOUD

Data selected for sync

If the user enables iCloud sync, data selected for sync and saved PDFs are stored in the user's own iCloud account.

03 / EXTERNAL SERVICES

Calendar and database information

Information from Apple Calendar, Google Calendar, and Notion is handled when the user connects to a service or fetches or registers information.

Calendar integrations

When a user selects an integrated service and destination and asks the app to fetch or register events, the app sends the information needed for that feature to the selected service. Event edits, deletions, and other supported actions are performed when the user requests them in the app.

Google Calendar API: The app uses the Google Calendar API to display calendar lists and events and to create, edit, or delete events selected by the user. OAuth access and refresh tokens are stored in the device's Keychain.

Google user data is used only to provide calendar features requested by the user and is not used for advertising. The app's use of data received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

Notion access tokens and other credentials are stored in the device's secure storage, as described in the in-app About section.

Storage and sharing

Scanned PDFs, event definitions, and destination settings are stored on the device. If iCloud sync is enabled, settings selected for sync and saved PDFs are stored in the user's private iCloud account. Information from Apple Calendar, Google Calendar, or Notion is sent to those services when the user connects, fetches, or registers information.

Advertising and external services

The app does not use PDFs or calendar contents selected by the user for advertising. Each calendar service's policies also apply to its services and the information stored there.

Contact

For privacy or data handling questions, contact us through the Support page. Remove personal or confidential information before including any data in a support request.
