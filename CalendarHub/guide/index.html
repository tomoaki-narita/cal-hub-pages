User Guide

カレンダーの接続から予定の登録、勤務表PDFの取込みまでをご案内します。

Learn how to connect calendars, manage events, and import work schedule PDFs.

Calendar Hubは、Appleカレンダー、Googleカレンダー、Notionデータベースのいずれかを選んで予定を管理します。各サービスの接続先を設定してから、カレンダー画面で予定を表示・登録してください。

1. カレンダーを接続する

アプリの「設定」から「カレンダー設定」を開き、登録先を選びます。予定の登録先はカレンダー画面上部の登録先メニューからも切り替えられます。

APPLE CALENDAR

Appleカレンダー

カレンダーへのアクセスを許可し、「カレンダー一覧を取得」を押して一覧から登録先を選びます。アクセスを拒否した場合は、端末のシステム設定でCalendar Hubのカレンダーアクセスを許可してください。

GOOGLE CALENDAR

Googleカレンダー

「Googleにログイン」を押してGoogleアカウントを選び、カレンダーへのアクセスを許可します。アプリに戻ったら「カレンダー一覧を取得」を押し、登録先を選択してください。

NOTION

Notionデータベース

「Notionに接続」からNotionへログインし、共有するデータベースを許可します。アプリに戻ってデータベース一覧を取得し、対象を選択します。続けてタイトル列と日付列を設定してください。タグや追加プロパティは必要に応じて設定できます。

Notionで共有を許可したデータベースだけがCal Hubに表示されます。目的のデータベースが見つからない場合は、Notionの接続画面でそのデータベースへのアクセスを許可してから、一覧を再取得してください。

2. 予定を登録・編集・削除する

手入力で登録

カレンダー画面の「＋」または日付の操作メニューから「イベントを登録」を選び、タイトルと開始・終了日時を入力します。登録前に登録先カレンダーを確認してください。

保存したイベントから登録

よく使うイベント名と時間は、設定の「イベント管理」に保存できます。カレンダーで日付を選び、「イベント一覧から選択」から登録するイベントを選びます。複数の日付を選択して、同じイベントをまとめて登録することもできます。

編集・削除

カレンダー上の編集可能な予定を選び、「編集」または「削除」を選択します。削除は確認してから実行してください。祝日など一部の表示専用項目は編集・削除できません。

3. 勤務表PDFから予定を登録する

  1. 「PDFスキャン」を開き、「PDFを選択」から勤務表を読み込みます。
  2. アプリに登録した名前に合う行または列と日付が読み取られます。必要に応じて名前を指定し、抽出結果をカレンダー表示または一覧表示で確認します。
  3. 勤務表の記号がイベント設定にない場合は、イベント名と時間を設定するか、その項目を登録対象から外します。
  4. 表示内容を確認し、登録先を選んでカレンダーへ登録します。「休」の予定を含めるかは登録時に選択できます。

PDFの条件:文字を選択・コピーできる文字情報があり、氏名と日付が表形式で並んでいるPDFが対象です。日付が横または縦に連続する対応レイアウトを読み取ります。スキャン画像だけのPDFや、表構造・日付を判別できないPDFには対応していません。

PDFから年月を取得できない場合は、ファイル名を「2026-01.pdf」のような「YYYY-MM.pdf」形式にしてください。

4. ウィジェット、Apple Watch、iCloud

ウィジェットとApple Watch

端末のウィジェット追加画面からCalendar Hubのウィジェットを配置します。iPhoneとペアリングしたApple Watchでは、Watchアプリや文字盤のコンプリケーションから予定を確認できます。

iCloud同期

新規インストールではオフです。有効にするとアプリ設定と保存済みPDFをiCloudで同期します。カレンダー上の予定とログイン情報は同期しません。同期をオフにしても既存のiCloudデータは残ります。削除する場合は「設定」>「一般」>「iCloud同期データを削除」を使ってください。

うまくいかないとき

カレンダーやDBが一覧に出ない

接続状態とサービス側のアクセス許可を確認し、「カレンダー一覧を取得」または「データベース一覧を取得」をもう一度実行してください。

PDFから予定が見つからない

PDF内の文字を選択できること、設定した名前がPDF内にあること、日付と表の並びが対応形式であることを確認してください。年月が取得できないときはファイル名も確認してください。

解決しない場合

問題の内容と操作手順をメールでお知らせください。

サポートへメール

Calendar Hub lets you choose Apple Calendar, Google Calendar, or a Notion database as your event destination. Set up a connection first, then view and manage events in the calendar screen.

1. Connect a calendar

Open Calendar Settings from the app's Settings and choose a destination. You can also switch the destination from the menu at the top of the calendar screen.

APPLE CALENDAR

Apple Calendar

Allow calendar access, choose Fetch Calendar List, and select a destination. If access was denied, allow Calendar Hub to access calendars in your device's system settings.

GOOGLE CALENDAR

Google Calendar

Choose Sign in with Google, select your account, and allow calendar access. Return to the app, fetch the calendar list, and select a destination.

NOTION

Notion database

Choose Connect to Notion, sign in, and allow access to the databases you want to share. Return to the app, fetch the database list, and select a database. Then choose its title and date properties. Tag and additional properties are optional.

Only databases allowed on Notion's authorization screen appear in Cal Hub. If a database is missing, grant access to it in Notion and fetch the list again.

2. Create, edit, and delete events

Create an event manually

Choose the plus button on the calendar screen, or open a date's action menu and select “Register event.” Enter a title and start and end times. Check the destination before saving.

Register a saved event

Save frequently used event names and times in Event Management in Settings. Choose a date, select “Choose from event list,” and pick an event. You can select multiple dates to register the same event on them.

Edit or delete

Select an editable event on the calendar and choose Edit or Delete. Confirm before deleting. Some display-only items, such as holidays, cannot be edited or deleted.

3. Register events from a work schedule PDF

  1. Open PDF Scan, select “Choose PDF,” and pick a work schedule file.
  2. Cal Hub reads the row or column matching the name saved in the app and the dates. Review the results in calendar or list view.
  3. If a shift label is not defined in Event Management, configure its event name and time when prompted, or choose not to register it.
  4. Review the results, choose the destination, and register them. You can choose whether to include days off.

PDF requirements:The PDF must contain selectable text and a table with names and dates in a supported layout. Cal Hub reads supported tables where dates run horizontally or vertically. Image-only scans and layouts whose table or date order cannot be identified are not supported.

If the year and month cannot be read from the PDF, name the file in YYYY-MM.pdf format, such as 2026-01.pdf.

4. Widgets, Apple Watch, and iCloud

Widgets and Apple Watch

Add a Calendar Hub widget using your device's widget gallery. On a paired Apple Watch, check events in the Watch app or with a complication on the watch face.

iCloud sync

Sync is off by default for new installations. When enabled, it syncs app settings and saved PDFs. Calendar events and sign-in credentials are not synced. Turning sync off leaves existing iCloud data in place. To delete it, choose Delete iCloud Sync Data in Settings > General.

Troubleshooting

A calendar or database is missing

Check the connection and service permissions, then fetch the calendar or database list again.

No events were found in the PDF

Check that PDF text can be selected, the saved name appears in it, and the table and date layout is supported. If the month was not detected, check the file name too.
