Get help with calendar integrations, work schedule PDFs, widgets, and Apple Watch.

Calendar Hub（Cal Hub）は、Appleカレンダー、Googleカレンダー、Notionを切り替えてイベントを管理するアプリです。勤務表PDFの取込みや、iPhone・iPad・Macのウィジェット、Apple Watchのコンプリケーションにも対応しています。お問い合わせには状況が分かる情報を添えてください。

お問い合わせ

質問、不具合の報告、機能の提案は、GitHubのサポートページからお送りください。

お問い合わせ時に含めてほしい情報

確認をスムーズに進めるため、可能な範囲で次の情報をお知らせください。

  • 端末とOSの種類・バージョン（macOS、iOSなど）
  • Cal Hubのバージョン
  • 問題が起きるまでの操作と、表示されたエラーメッセージ
  • 問題が起きた機能（PDFスキャン、Googleカレンダー連携など）
  • 個人情報を隠したスクリーンショット（必要な場合）

よくある項目

01 / PDF TO EVENTS

勤務表PDFから予定登録

文字を選択でき、日付が横または縦に連続する表形式のPDFが対象です。画像だけのPDFや、対応する表のレイアウトでないPDFは読み取れない場合があります。設定した名前に一致する勤務欄が見つからない場合は、名前とPDFのレイアウトをお知らせください。PDF本体は添付しないでください。

02 / CALENDARS

Apple・Google・Notion

接続や予定の取得・登録で問題が起きた場合は、対象サービス、選択した登録先、操作、エラー表示をお知らせください。

03 / WIDGETS & WATCH

ウィジェットとApple Watch

予定が表示されない場合は、どのウィジェットや文字盤のコンプリケーションを使っているか、アプリ本体で同じ予定を確認できるかをお知らせください。

04 / ICLOUD

iCloud同期

設定と保存済みPDFの同期については、iCloud同期が有効か、端末で同じApple Accountを使用しているか、どの情報が同期されないかをお知らせください。

お問い合わせ時のプライバシー

パスワード、OAuth認証コード、アクセストークン、リフレッシュトークン、Notionトークン、個人的な予定の詳細、PDFの内容などの機密情報は投稿しないでください。

添付するスクリーンショットやエラー表示から、名前、メールアドレス、予定の内容などを隠してください。

プライバシーポリシー

PDFや設定の保存先、カレンダー連携で扱う情報については、プライバシーポリシーをご確認ください。

Calendar Hub (Cal Hub) helps users switch between Apple Calendar, Google Calendar, and Notion to manage events. It also supports work schedule PDF import, widgets on iPhone, iPad, and Mac, and Apple Watch complications. Please include details that help us understand the issue.

Questions, issue reports, and feature suggestions

What to include

When possible, include the following information so we can investigate:

  • Device and OS type and version (macOS, iOS, etc.)
  • Cal Hub version
  • Steps leading to the issue and any error message
  • The feature involved (PDF scan, Google Calendar integration, etc.)
  • A screenshot with personal information hidden, if needed

Common topics

01 / PDF TO EVENTS

Work schedule PDF import

The app requires a PDF with selectable text and a supported table layout where dates run horizontally or vertically. Image-only PDFs or other layouts may not be recognized. If a schedule row matching your saved name is not found, tell us the name setup and PDF layout. Do not attach the PDF itself.

02 / CALENDARS

Apple, Google, and Notion

For connection or event issues, include the service, selected destination, action you took, and the error shown.

03 / WIDGETS & WATCH

Widgets and Apple Watch

If events do not appear, tell us which widget or watch face complication you use and whether the same events appear in the app.

04 / ICLOUD

iCloud sync

For settings and saved PDF sync issues, tell us whether iCloud sync is enabled, whether devices use the same Apple Account, and what is not syncing.

Privacy when contacting support

Do not post passwords, OAuth authorization codes, access or refresh tokens, Notion tokens, private event details, PDF contents, or other confidential information.

Hide names, email addresses, event details, and other personal information in screenshots or error messages.
