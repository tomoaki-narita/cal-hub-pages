よくある項目

01 / PDF TO EVENTS

勤務表PDFから予定登録

文字を選択でき、日付が横または縦に連続する表形式のPDFが対象です。画像だけのPDFや、対応する表のレイアウトでないPDFは読み取れない場合があります。設定した名前に一致する勤務欄が見つからない場合は、名前とPDFのレイアウトをお知らせください。PDF本体は添付しないでください。

02 / CALENDARS

Apple・Google・Notion

接続や予定の取得・登録で問題が起きた場合は、対象サービス、選択した登録先、操作、エラー表示をお知らせください。

03 / EVENT LIST

イベント一覧に保存される内容

イベント一覧にはタイトルと開始・終了時刻のみ保存され、日付は保存されません。そのため、日付をまたぐイベントはイベント一覧に登録できません。日付をまたぐイベントを登録する場合は、トップ画面から開始日と終了日を指定してください。

04 / WIDGETS & WATCH

ウィジェットとApple Watch

予定が表示されない場合は、どのウィジェットや文字盤のコンプリケーションを使っているか、アプリ本体で同じ予定を確認できるかをお知らせください。

05 / ICLOUD

iCloud同期

設定・保存済みPDF・操作履歴が同期されない場合は、両端末のiCloud同期が有効で同じApple Accountを使用しているかをご確認ください。アプリを開き、通信状態を確認して「今すぐ同期」をお試しください。接続先サービスの選択と認証情報は端末ごとに管理します。解決しない場合は、どの端末からどの端末へ、何が反映されないかをお知らせください。

登録・削除の結果と操作履歴

「設定」>「一般」>「操作履歴」で、操作日時、対象期間、登録先、登録・削除の結果を確認できます。直近50回・予定合計1,000件を上限に保存します。履歴は過去の操作の記録です。カレンダー側で後から変更・削除した予定の現在の状態とは異なる場合があります。

結果が「不明」や「反映未確認」の場合は、重複登録を避けるため、再登録する前に登録先サービスで実際の予定を確認してください。お問い合わせには、登録か削除か、操作した日時、対象期間、表示された結果やエラー、使用したサービスを、個人情報を除いてお知らせください。

履歴を消去するには、この画面の「履歴を消去」を使います。iCloud同期が有効な場合は他の同期端末にも消去を反映します。同期がオフの端末には、再度同期するかその端末で消去するまで履歴が残ります。履歴を消去しても、カレンダー上の予定は削除されません。同期をオフにするだけでは、端末やiCloudの履歴は消えません。

お問い合わせ時のプライバシー

パスワード、OAuth認証コード、アクセストークン、リフレッシュトークン、Notionトークン、個人的な予定の詳細、PDFの内容などの機密情報はメールに記載しないでください。

操作履歴にも予定の内容や登録先情報が含まれます。スクリーンショットを添付する場合は、名前、メールアドレス、予定・履歴の内容、メモ、場所、URL、登録先情報などを隠してください。

Common topics

01 / PDF TO EVENTS

Work schedule PDF import

The app requires a PDF with selectable text and a supported table layout where dates run horizontally or vertically. Image-only PDFs or other layouts may not be recognized. If a schedule row matching your saved name is not found, tell us the name setup and PDF layout. Do not attach the PDF itself.

02 / CALENDARS

Apple, Google, and Notion

For connection or event issues, include the service, selected destination, action you took, and the error shown.

03 / EVENT LIST

What the event list saves

The event list saves a title and start and end times, but not a date. It cannot store events that cross midnight. To register a cross-midnight event, set its start and end dates from the home screen.

04 / WIDGETS & WATCH

Widgets and Apple Watch

If events do not appear, tell us which widget or watch face complication you use and whether the same events appear in the app.

05 / ICLOUD

iCloud sync

If settings, saved PDFs, or operation history do not sync, check that iCloud sync is enabled on both devices using the same Apple Account. Open the app, check the network connection, and try Sync now. The selected connection service and credentials are managed separately on each device. If the issue persists, tell us which information is missing and the source and destination devices.

Registration/deletion results and action history

In Settings > General > Action History, review action times, date ranges, destinations, and registration/deletion results. The app keeps up to 50 recent actions and 1,000 event results in total. History records past actions and may differ from the current state of an event that was later changed or deleted in the calendar service.

If a result is unknown or not yet confirmed in the event list, check the destination service before registering again to avoid duplicates. When contacting support, include whether you registered or deleted an event, the action time, date range, result or error message, and the service used, with personal information removed.

Use Clear History on this screen to remove history. When iCloud sync is enabled, clearing also applies to other syncing devices. A device with sync turned off retains history until it syncs again or history is cleared on that device. Clearing history does not delete calendar events. Turning sync off alone does not remove local or iCloud history.

Privacy when contacting support

Do not include passwords, OAuth authorization codes, access or refresh tokens, Notion tokens, private event details, PDF contents, or other confidential information in email.

Operation history can also contain event details and destination information. In screenshots, hide names, email addresses, event and history details, notes, locations, URLs, destination information, and other personal information.
